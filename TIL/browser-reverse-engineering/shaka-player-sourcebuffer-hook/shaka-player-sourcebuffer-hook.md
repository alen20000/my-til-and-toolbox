# 影片串流防爬
## 問題描述:
* 目標網站使用 Google的 Shaka Player JS庫進行影片保護，有以下幾點特徵。
1. 無法像常規手段，去抓到串流清單或捕捉常見串流分片格式
2. 串流分片被偽裝為.png外殼
3. 對方不是僅僅的改變副檔名，因為用二進制處理沒辦法合併<br>目標網站是真的把分片做像素編碼由二進制轉為彩色漸層的圖檔

## 解決方向

* 就算作多層次的隱藏，但瀏覽器播放時還是要渲染，最終也要在客戶端上做還原
* 透過 JS Hook 攔截 Media Source 核心的 `SourceBuffer.prototype.appendBuffer`。當 Shaka Player 在背景將偽裝的圖檔解密並準備送入播放緩衝區時，直接在記憶體中攔截並擷取解密後的真實影音二進位片段
