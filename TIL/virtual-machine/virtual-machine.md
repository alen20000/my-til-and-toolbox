## 安裝步驟

* I、先安裝虛擬機 VMware Workstation Pro
* II、解壓縮 Windows XP VMware成品虚拟机
* III、 打開 VMware Workstation Pro ，選擇`Use VMware Workstation 17 for Personal Use` 不需要輸入金鑰，進入虛擬機畫面，點選`Open a Virtual Machine`，把路徑指向解壓縮後的虛擬機預設檔案`Windows XP Professional`

## 其他選項 

### 添加共用資料夾: 

對目標VM右鍵 -> `setting` -> Options -> Shared Folders ，這邊設定要共用的資料夾，勾選`Map as a network drive in Windows guests` 則可以在VM中看見共用資料夾的磁碟機


### CD掛載/ISO掛載

對目標VM右鍵 -> `setting`  -> 下方選項 CD/DVD -> 勾選 `connected` 與 `connect at power on` -> 掛載鏡像檔
